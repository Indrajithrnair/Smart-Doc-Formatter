# Document Templates

This directory contains template documents for different formatting scenarios.

## Business Proposal Template

Place your business proposal template with placeholders here:
- `business_proposal_template.docx` - Main business proposal template

## Template Placeholders

Use these placeholder formats in your template:
- `{{COMPANY_NAME}}` - Company name
- `{{PROJECT_TITLE}}` - Project or proposal title
- `{{EXECUTIVE_SUMMARY}}` - Executive summary content
- `{{PROBLEM_STATEMENT}}` - Problem description
- `{{PROPOSED_SOLUTION}}` - Solution details
- `{{TIMELINE}}` - Project timeline
- `{{BUDGET}}` - Budget information
- `{{TEAM_MEMBERS}}` - Team information
- `{{CONTACT_INFO}}` - Contact details

## Usage

The agent will:
1. Analyze the input document to extract relevant content
2. Map content to appropriate template sections
3. Replace placeholders with extracted content
4. Apply consistent formatting
